# Security Policy

## Supported versions

Security fixes are provided for the latest release.

## Report a vulnerability

Do not open a public issue. Report the problem to the maintainer in private through GitHub.

Include:

- What the issue is and why it matters
- Steps to reproduce the problem
- Any fix or workaround you know

We will reply as soon as possible. Please give us time to fix the issue before you share it in public.

## Security updates

When a fix is ready, we will publish a patch and update the docs. We can credit you if you want.

Thank you for helping keep SpreadNext safe.
