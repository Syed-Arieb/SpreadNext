# Contributing to SpreadNext

Thanks for helping make SpreadNext better.

## Report a bug or request a feature

Open an issue on GitHub. Include:

- What happened
- Steps to reproduce the problem
- What you expected to happen
- Screenshots if they help

## Submit code changes

1. Fork the repo and create a branch.
2. Install dependencies with `npm install`.
3. Make your changes.
4. Run `npm run build`. If you changed the formula engine, also run `npm run build:wasm`.
5. Run `npm test` if your change affects tested code.
6. Open a pull request and explain what changed and why.

## Code of Conduct

Follow the [Contributor Covenant](https://www.contributor-covenant.org/version/2/0/code_of_conduct/).
